# Bean Blvd RC Rentals

Offline rental timer for the RC cars (₱45 / ₱30 per 15 minutes).

Live app: https://geeannlopez.github.io/rental-timer/

## Install on the Android tablet
1. Open the link above in Chrome.
2. Menu → **Install app** (or **Add to Home screen**).
3. It now works with no internet. All rentals are saved on the tablet.

## Daily
- Tap **Download today (CSV)** at closing as a backup.
- Don't clear Chrome's site data for this app, or the log is erased.

## Updating
Push changes to `main`. Bump `CACHE` in `sw.js` so the tablet picks up the new version the next time it's online.
